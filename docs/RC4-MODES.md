# 1.0.0-rc.4 — coordenação com o protótipo 2.5D

Acrescenta a primeira opção SELECT **Modo de batalha** e a opção correspondente no gerenciador: 2D / 2.5D / Original. Os dois mods podem ficar carregados, mas apenas um renderiza e recebe os comandos da apresentação. A escolha é persistida pelo gerenciador nativo; não desativa o outro mod no gerenciador. 2.5D só fica disponível quando instalado e carregado. Os demais recursos do 2D permanecem os mesmos.

Carregador API 3, alternância com o 2.5D e ciclo de vida testados nos cinco jogos via SDK. Sem validação Android nesta revisão.
